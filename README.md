# openGym 简体中文版安装包下载

这是独立简体中文版 1.0.0 的签名测试候选，APK 约 219 MiB。此分支专门用于分发，应用源码仍在 `feature/zh-cn-complete` 分支中。

## 在安卓手机上获取 APK

1. [下载完整 ZIP 包](https://github.com/Coney97/openGym-/archive/refs/heads/apk-download-20261108.zip)。请等待下载全部完成。
2. 解压 ZIP，在浏览器中打开其中的 **生成APK.html**。页面可完全离线运行，不会上传你的文件。
3. 在页面中选中解压后的五个 `part01` 至 `part05` 文件，点击“校验并生成”。校验完成后点击“下载 APK 安装包”，再从手机的下载目录打开 APK 安装。

如果文件管理器只显示 HTML 预览，请选择“用其他应用打开”，使用支持本地网页的浏览器。不要直接安装分片文件，也不要把普通分片改名为 APK。
