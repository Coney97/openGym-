# 从 Beta 迁移到独立简体中文版

独立应用名称为“openGym 简体中文版”，包名为 `io.github.coney97.opengym.zh`。它使用独立正式签名，与原版、简中 Beta 并存，不会覆盖或读取它们的私有数据。

1. 打开原版或 Beta，进入“设置 → 数据与备份”。如果有自定义动作照片或训练视频，请选择包含照片和视频的备份；只有训练数据时也可以导出 JSON 备份。
2. 将备份保存到自己能找到的位置。保留原始文件；含媒体的 ZIP 不要解压后重新压缩。
3. 安装独立中文版，进入“设置 → 数据与备份 → 导入备份”，选择刚才导出的 JSON 或 ZIP，核对导入提示后确认。
4. 检查训练计划、训练历史、体重、重量单位以及自定义图片和视频，再开始新训练。确认数据完整前，保留原应用和备份文件。

用户自己填写的动作、计划和训练名称会原样保留。导入英语语言设置后，独立中文版的界面仍使用简体中文。动作编号、重量、次数和日期不会因汉化而改写。

旧 NFC 贴纸或桌面入口可能仍指向原应用。迁移后，请在中文版重新写入贴纸，并添加新的快捷方式和小组件。

中文版的专用分享链接需要对方安装中文版。与原版或 Beta 用户交换计划时，请使用计划菜单导出的计划文件；文件中的动作编号和训练配置保持兼容。

本应用的更新仅使用 `Coney97/openGym-` 仓库中的中文发行系列，标签以 `zh-CN-v` 开头。不要将原版或 Beta 的 APK 当作独立中文版的更新包；它们的包名和签名不同。
