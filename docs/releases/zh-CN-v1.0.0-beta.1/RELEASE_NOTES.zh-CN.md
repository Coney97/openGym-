## 安装与迁移

下载 `openGym-zh-CN-1.0.0-candidate.apk`，按 Android 的安装提示操作。安装前可用同名 `.apk.sha256` 文件核对完整性。首次尝试前，请先从原版或 Beta 导出 JSON 或含媒体 ZIP 备份，详细步骤见附件 `MIGRATION.zh-CN.md`。

此包的版本代码为 1，后续安装本独立中文版的更新包需要相同包名、相同签名及更高版本代码。不要用原版或旧 Beta 的 APK 覆盖更新。
